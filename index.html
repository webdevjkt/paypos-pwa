Cara Install Aplikasi PayPOS

PayPOS dibuat menggunakan teknologi Progressive Web App (PWA), sehingga dapat dipasang langsung di semua jenis perangkat tanpa perlu download dari PlayStore/AppStore:

📱 Android (Google Chrome)
  1. Buka halaman ini di browser Google Chrome.
  2. Klik tombol hijau "Install Aplikasi" atau tekan menu titik tiga (⋮) di kanan atas.
  3. Pilih "Tambahkan ke Layar Utama" (Add to Home screen) / "Install Aplikasi".
💻 Laptop / PC (Chrome & Edge)
  1. Buka di browser Google Chrome atau Microsoft Edge.
  2. Klik ikon Install (🖥️ / ➕) yang muncul di bagian kanan bilah alamat URL.
  3. Klik "Install" dan aplikasi kasir akan langsung muncul di Desktop.
🍎 iPhone / iPad (Safari)
  1. Buka di browser Safari.
  2. Tekan tombol Share (ikon kotak dengan panah ke atas di bilah bawah).
  3. Gulir ke bawah dan pilih "Tambahkan ke Layar Utama" (Add to Home Screen).
