Koneksi Printer Thermal Bluetooth

Hubungkan printer kasir mini Bluetooth (58mm / 80mm ESC/POS) langsung tanpa kabel.

Terputus
🍎
iPhone / iPad tidak mendukung Cetak Bluetooth Langsung

Apple melarang akses Web Bluetooth di semua browser iOS (Safari, Chrome, Firefox). Ini bukan bug aplikasi — ini kebijakan Apple.

Alternatif cetak dari iPhone:

  • 📱 Kirim WhatsApp — Gambar struk bisa dikirim ke nomor pelanggan
  • 🖨️ AirPrint — Jika printer mendukung AirPrint (tekan Share → Print)
  • 📲 Gunakan HP Android — Untuk cetak Bluetooth langsung ke thermal printer
🖨️
PERANGKAT TERHUBUNG
Belum Terhubung
💡 Kompatibilitas Printer Bluetooth:
  • Mendukung semua printer thermal Bluetooth ESC/POS (seperti Panda, RPP02N, Zywell, Iware, Eppos, VSC, Zjiang 58mm/80mm).
  • Pastikan Bluetooth di HP / Laptop Anda sudah dalam kondisi Aktif (ON).
  • Gunakan Google Chrome di Android atau Desktop untuk koneksi Bluetooth langsung.
  • iPhone/iPad (iOS): Tidak mendukung Web Bluetooth — gunakan fitur Kirim WhatsApp sebagai alternatif.
